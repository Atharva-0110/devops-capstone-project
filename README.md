## Project Description

This project develops a RESTful customer accounts microservice for an e-commerce application using Python and Flask.

The service manages customer accounts and supports creating, reading, updating, deleting, and listing customer records. The project also covers development environment setup, Agile planning using GitHub Projects, and future containerization with Docker and deployment to Kubernetes.
